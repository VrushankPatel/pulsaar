# Security Policy

## Supported Versions

We actively monitor and support the following versions of Pulsaar:

| Version | Supported          |
| ------- | ------------------ |
| v1.1.x  | :white_check_mark: |
| < v1.1  | :x:                |

## Reporting a Vulnerability

We take the security of Pulsaar seriously. If you find a security vulnerability, please do **not** report it via a public GitHub issue. Instead, please report it via the security vulnerability reporting process:

1. Send an email to [vrushankpatel@gmail.com] with a description of the issue, steps to reproduce, and any potential impact or proof of concept.
2. We will acknowledge receipt of your email within 48 hours and work with you to analyze and resolve the issue.
3. Once the issue is resolved, we will publish a security advisory and issue a patch release.

Thank you for helping keep Pulsaar secure for everyone!
