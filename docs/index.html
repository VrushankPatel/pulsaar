End-to-End Secure Architecture

How Pulsaar leverages native Kubernetes security features to deliver auditable read-only path access.

🛡️

Read-Only Safety

Enforces strict read-only file logic inside pods. No file modification operations are exposed or possible.

🔑

mTLS Security

Automatic generation of self-signed TLS certificates for secure and encrypted end-to-end communication.

📝

Auditable Logs

Every execution path is logged and securely reported to a central aggregator. Failures block the request.

⚡

Sidecar or Ephemeral

Deploy permanently as a sidecar via admission controller, or inject temporarily as an ephemeral container.

Client CLI

Install CLI via Homebrew

Get the pulsaar control utility on macOS or Linux.

brew tap VrushankPatel/homebrew-pulsaar && brew install pulsaar-cli
Kubernetes Cluster

Deploy Agent via Helm

Deploy mutating webhook and audit logger in your cluster.

helm repo add pulsaar https://vrushankpatel.github.io/pulsaar && helm install pulsaar pulsaar/pulsaar
